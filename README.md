#  Restaurant Inventory Management System

A web-based inventory management system designed to help restaurants manage their stock, expenses, sales, and profitability from a centralized dashboard.

##  Features

-  Inventory tracking
- Low-stock alerts
-  Expense management
-  Sales tracking
-  Profit summary
-  Restaurant dashboard

##  Tech Stack

- Python
- HTML
- CSS
- JavaScript
- Supabase

##  Purpose

The system is designed to reduce manual inventory tracking and give restaurant owners a centralized view of their operational data.
